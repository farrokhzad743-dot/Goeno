# Goeno VPN (فیلترشکن هوشمند گوئنو)

An open-source, lightweight, and smart Android VPN client featuring **Xray-core**, automatic server selection (`SmartRouter`), and a minimal bilingual (Persian/English) interface.

## Features / ویژگی‌ها
- ⚡ **Smart Auto-Routing**: Automatically tests latency and connects to the fastest available node.
- 🌐 **Bilingual (FA / EN)**: Fully localized for Persian and English users.
- 📱 **Minimal UI**: Clean, distraction-free user interface built with Material 3 design principles.
- 🤖 **GitHub Actions CI/CD**: Automatic APK build workflow without requiring local Android Studio setup.

## How to Build on GitHub / نحوه بیلد در گیت‌هاب
1. Create a new repository on GitHub named `Goeno`.
2. Upload all files from this ZIP.
3. Go to the **Actions** tab in your GitHub repository to watch the automatic build of your Android APK!
